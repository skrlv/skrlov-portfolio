# skrlov — портфолио

Публичный сайт: https://skrlv.github.io/skrlov-portfolio/

Минималистичное портфолио с горизонтальной галереей. Обычная вертикальная прокрутка плавно перемещает восемь экранов: вступление, шесть проектов и контакт. После остановки прокрутки галерея выравнивает ближайший экран.

## Возможности

- Загрузочный экран с заполнением ника skrlov по готовности локальных превью; есть пропуск и ограничение ожидания.
- Шесть актуальных превью, описания и прямые ссылки на опубликованные сайты.
- Навигация стрелками, клавишами ← / →, Home / End и указателем экранов.
- Контакт в Telegram: https://t.me/skrlov.
- Отдельный режим списка. Он включается по умолчанию при уменьшенном движении или небольшой высоте окна. Без JavaScript проекты также доступны списком.
- Неактивные экраны исключаются из клавиатурной навигации; выбранный экран объявляется вспомогательным технологиям.
- Все ресурсы локальные; нет аналитики, форм отправки данных или внешних зависимостей.

## Локальный просмотр

Из каталога проекта:

```sh
python3 -m http.server 4185 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4185/. Для проверки на пути репозитория можно запустить сервер из родительского каталога и открыть `/skrlov-portfolio/`.

```sh
npm test
npm run check
```

Сборка не требуется. GitHub Actions проверяет исходники и публикует только файлы интерфейса в GitHub Pages. `social-preview.html` — вспомогательный макет изображения для ссылок, в публикацию он не входит. Превью и сведения об источниках описаны в ASSETS.md.

G2 — демонстрационная адаптация предоставленного пользователем магазина одежды. Пять других работ — самостоятельные демонстрационные концепции. Они не выдаются за выполненные коммерческие заказы.

Визуальное направление повторяет G2: почти чёрный фон, светлая типографика, тонкие линии, локальные Onest / Unbounded / JetBrains Mono. Превью монохромные; при наведении или фокусе возвращают цвета оригинальных сайтов.
