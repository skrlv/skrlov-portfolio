# Превью проектов

Превью — скриншоты шести сайтов из портфолио skrlov. Все изображения сохранены локально: при открытии портфолио не нужны внешние сервисы изображений и встроенные страницы проектов.

| Файл                | Размер     | Проект                       | Публичный сайт                                   |
| ------------------- | ---------- | ---------------------------- | ------------------------------------------------ |
| `assets/g2.jpg` | 1280 × 720 | G2 — бренд одежды | https://skrlv.github.io/g2-fashion-demo/ |
| `assets/forma.jpg`  | 1280 × 720 | ФОРМА — архитектурное бюро   | https://skrlv.github.io/forma-architecture-demo/ |
| `assets/tishe.jpg`  | 1280 × 720 | ТИШЕ — бутик-отель           | https://skrlv.github.io/tishe-retreat-demo/      |
| `assets/obekt.jpg`  | 1280 × 720 | ОБЪЕКТ — дизайнерская мебель | https://skrlv.github.io/obekt-design-demo/       |
| `assets/pauza.jpg`  | 1280 × 720 | ПАУЗА — кофейня              | https://skrlv.github.io/pauza-coffee-demo/       |
| `assets/chisto.jpg` | 1280 × 720 | ЧИСТО — клининг              | https://skrlv.github.io/chisto-cleaning-demo/    |

Пять прежних превью побайтно скопированы из соответствующих `*-refined-public.png` в соседней папке `outputs`, без изменения качества, размеров или содержимого. Исходные снимки, несмотря на расширение `.png`, содержат JPEG/JFIF; в портфолио использовано правильное расширение `.jpg`.

Скриншоты показывают интерфейсы демонстрационных проектов, а не фотографии выполненных коммерческих заказов. Права на исходные фотографии внутри сайтов принадлежат их авторам. Источники и сведения об использовании фотографий указаны в `ASSETS.md` или `README.md` соответствующих проектов: `forma-architecture`, `tishe-retreat`, `obekt-design`, `pauza-coffee`, `chisto`.

`assets/g2.jpg` — новый снимок демонстрационной версии G2. Все шесть превью имеют размер 1280 × 720. CSS использует чёрно-белый фильтр для спокойной общей подачи; исходные файлы остаются цветными.

## Обложка ссылки

`assets/cover.jpg` — собственная типографическая обложка skrlov, созданная из вспомогательного макета `social-preview.html`. Формат JPEG, 1280 × 720.

## Шрифты

Локальные Onest, Unbounded и JetBrains Mono перенесены из предоставленного пользователем проекта G2. Используются латинские и кириллические срезы WOFF2. Лицензия SIL Open Font License хранится рядом с файлами каждого семейства в `assets/fonts/`.
